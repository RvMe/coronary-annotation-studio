# 旧版导入与故障排查

## 显式导入旧数据

支持旧版 ImageCAS-X 数据包和完整标签导出。工具验证原文件后，在新的独立项目中建立记录，保留原 schema、来源和审计证据。
不会连接或迁移正在使用的旧数据库。

```console
python -m annotation_app import-legacy-package /old/package /new/package --project-id imported-study-v1
python -m annotation_app import-legacy-labels /old/export/annotations.json --case /new/package/case-id/case.json
```

数据包目的地必须为源目录以外的新目录，影像会复制到该目录。请选合适的数据位置，不要复制到源码仓库。
标签导入要求四个原文件齐全：`annotations.json`、`annotations.csv`、`audit.jsonl`、`checksums.json`。
校验包括哈希、读者/病例身份、连续审计修订和几何身份。原始字节会作为 base64 保留在导入审计里，原始文件不改动。
已有冲突记录会被拒绝，不会覆盖其他读者或另一个版本。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 没找到数据包 | 选择直接包含 `manifest.json` 的目录，先解压 ZIP，不选混合项目的父目录 |
| 校验失败 | 恢复完整来源文件，核对损坏原因 |
| 项目或几何不一致 | 打开正确项目和对应几何版本；病例编号相同不足以证明可混用 |
| 映射超出范围 | 回到有效 CPR 范围，减少离轴或旋转；不会外推虚假的原始坐标 |
| 影像暂时离线 | 重连原目录后继续阅片，已存标签仍可离线导出 |
| 工作区已被打开 | 使用已有窗口；锁用于防止同时编辑同一项目 |
| 导入缺少审计 | 恢复完整结果文件夹，单独 JSON 无法完成可靠导入 |
| 恢复后显示草稿 | 核对后点击应用；程序不会自动将草稿当成正式标签 |

反馈问题时提供版本、系统架构、具体错误和最小合成复现。不要上传真实患者影像、私人标签数据库或未脱敏日志。
公开贡献采用 Apache-2.0；几何、序列化、恢复和隔离逻辑的修改需要对应测试，界面修改需分别核对英文和中文。
