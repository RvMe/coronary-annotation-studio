# Changelog

## 0.1.0 — initial public release candidate

- Independent, neutral coronary annotation application with English and Simplified Chinese.
- Versioned packages with explicit project, path, scope, HU and LPS geometry declarations.
- Frame and dense coordinate-field mappings; existing-CPR Slicer export adapter.
- Reader-local intervals, audit history, draft recovery and offline batch export.
- Explicit legacy package and complete-export import preserving historical evidence.
- Synthetic examples and cross-platform release acceptance materials.

Release status and actual tested environments are tracked separately in the
acceptance report. A candidate is not a published release.
