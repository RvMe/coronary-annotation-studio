# Third-party software

The desktop runtime uses Python, PySide6/Qt, Shiboken, SimpleITK, NumPy, SciPy,
pynrrd and their transitive native dependencies. PyInstaller is a packaging tool.
The Slicer adapter runs inside an independently installed 3D Slicer; Slicer/VTK
are not embedded in the desktop application.

Each binary release includes `DEPENDENCIES.json`, actual wheel/runtime license
text under `third_party_licenses`, and version-matched QtBase and PySide source
archives under `third_party_sources`. These materials are collected from the
actual build environment and checked against the distributed binaries.

Qt/PySide libraries remain dynamically linked in an unpacked application bundle.
Their license terms, including applicable modification, relinking and reverse
engineering rights for debugging modified libraries, are not restricted by the
application license. Replace compatible dynamic libraries in a private copy;
macOS may require ad-hoc re-signing that modified copy.

Synthetic demonstration volumes are generated by `annotation_app/synthetic.py`.
No external patient dataset is included. Historical schema names in the legacy
importer are retained for accurate compatibility and provenance.
